\section{什么不是经济学}
大家肯定或多或少都对经济学有所耳闻，或在课本上有所接触，但可能大多数人对它的印象和事实上学界进行的经济学研究存在一些偏差。

\begin{questionbox}{你觉得以下这些是经济学的研究内容吗？}
\begin{itemize}
    \item 预测经济发展、增长和波动
    \item 帮助政府制定财政和货币及各种其他政策
    \item 分析为什么有些国家比其他国家更富裕
    \item 
    \item 今天我应该投资什么股票才能赚大钱，未来房价会是什么走向
\end{itemize}
\end{questionbox}
